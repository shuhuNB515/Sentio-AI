# Sentio-AI Demo 视频讲解稿

> 录制时长：约6分钟
> 录制工具：OBS Studio / Windows 自带录屏（Win+G）
> 讲解方式：边操作边解说

---

## 第0段：项目结构 + 启动前后端（40秒）

> **画面**：先展示 VS Code/文件管理器中的项目目录结构，然后打开两个终端

大家好，这是 **Sentio-AI**，一个实时视觉 AI 对话助手。

先看项目结构：`frontend/` 是 Vue 3 前端，`backend/` 是 Flask 后端，部署配置在 `.github/workflows/`。

现在启动。

> **画面**：终端1 执行 `python app.py`，看到 "Running on http://127.0.0.1:5000"

```bash
cd backend
python app.py
```

后端启动，Flask 运行在 5000 端口。

> **画面**：终端2 执行 `npm run dev`，看到 "Local: http://localhost:5173"

```bash
cd frontend
npm run dev
```

前端启动，Vite 开发服务器在 5173 端口，自动打开浏览器。

---

## 第1段：打开浏览器 + 登录（30秒）

> **画面**：浏览器打开 `http://localhost:5173`，展示登录页，背景图+雨滴动画

浏览器打开 `localhost:5173`。登录页有雨滴动画特效和背景图。

输入账号 `shuhu`，密码 `shuhuNB560`，点击登录。

后端使用 JWT Token + bcrypt 密码哈希认证。登录后进入主界面：左侧对话列表，中间摄像头和聊天区，右侧识别记录。

---

## 第2段：打开摄像头 + 滤镜（35秒）

> **画面**：点击底部摄像头按钮 → 浏览器弹出权限请求 → 允许 → 实时画面出现。然后切换滤镜（无→赛博→复古→素描）

点击摄像头按钮。`localhost` 是安全上下文，浏览器允许 `getUserMedia`。

画面出来之后，点击滤镜按钮，可以切换**赛博朋克、复古、素描**三种实时滤镜。这是 Canvas 像素级处理实现的。

---

## 第3段：多模态对话（35秒）

> **画面**：打开摄像头状态下，输入框输入"你看到了什么？"，回车，等待AI回复

现在演示多模态对话。摄像头开着，输入"你看到了什么？"。

AI 调用视觉模型分析当前画面，返回描述。

系统支持两种调用模式：后端模式走 Flask 转发，直连模式浏览器直接调 API——等一下演示。

---

## 第4段：API 直连设置（30秒）

> **画面**：点齿轮图标打开设置 → 滚到"API 直连" → 打开开关 → 填入 API Key 和 Base URL → 保存

打开设置面板。滚到"API 直连"部分。开启开关。

填入你的 API Key 和 Base URL——支持任何 OpenAI 兼容接口，比如 MIMO、DeepSeek、通义千问等。保存设置。

之后所有 AI 请求都从浏览器直接发出，不需要走后端中转。这是一个**完全原创的功能设计**。

---

## 第5段：语音输入 + STT（35秒）

> **画面**：点击麦克风按钮 → 浏览器弹出麦克风权限 → 允许 → 开始录音，说话"请介绍一下你自己" → 松开或自动停止 → 文字出现在输入框 → 自动发送 → AI 回复

点击麦克风按钮，浏览器请求麦克风权限。允许后开始录音。

我说："请介绍一下你自己"。系统通过 `MediaRecorder` 录制音频，转成 WAV 格式，发送到 STT 语音识别 API。返回的文字自动填入输入框并发送。AI 回复后，如果开启 TTS，还会用语音朗读出来。

---

## 第6段：截图分析（25秒）

> **画面**：点击截图按钮（相机图标） → AI 分析画面 → 结果出现在对话框中

点击相机按钮截图。系统抓取当前摄像头帧、压缩后发给视觉模型分析。结果直接显示在对话框里。

---

## 第7段：前后对比（35秒）

> **画面**：打开工具栏 → 点击拍第一张 → 改变一下场景（比如用手挡住摄像头再松开） → 拍第二张 → 点"对比"按钮 → AI 分析两张图的差异

工具栏里有一个**前后对比**功能。先拍第一张照片。

然后改变场景——我挡住摄像头再松开。拍第二张。

对比按钮会分别描述两张图片，然后让 AI 分析差异。比如它会说："第一张有人物，第二张画面被遮挡，可能是手挡住了摄像头"。

---

## 第8段：对话管理 + 删除弹窗 + 退出登录（30秒）

> **画面**：左侧边栏新建对话 → 切换回旧对话 → 点删除按钮 → 确认弹窗出现（含图片） → 取消 → 再点右上角退出 → 确认弹窗 → 确认退出

左侧边栏可以新建对话、切换对话。删除时会弹出确认窗口，包含提示图片。

最后点退出登录，同样弹出确认弹窗。确认后回到登录页。

---

> **画面**：打开新标签页，输入 `https://shuhu.me`，展示线上版本。地址栏显示🔒锁图标，说明是HTTPS

登录进去，验证摄像头和麦克风在线上 HTTPS 环境下也能正常工作。和本地开发体验完全一致。
