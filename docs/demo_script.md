# Sentio-AI Demo 视频讲解稿

> 建议录制时长：3-5 分钟
> 录制工具：OBS Studio / Windows 自带录屏
> 讲解方式：边操作边解说（或后期配音）

---

## 开场（30秒）

> **画面**：展示 `https://shuhu.me` 登录页面，背景图 + 雨滴动画特效

大家好，这是 **Sentio-AI**，一个**实时视觉 AI 对话助手**。它能通过你的摄像头看到世界，通过麦克风听到你的声音，并用 AI 进行多模态理解和回复。

项目采用 Vue 3 构建前端，Flask 搭建后端，对接 OpenAI 兼容的 MIMO 多模态大模型。支持 GitHub Pages 和 PythonAnywhere 双端部署。

---

## 第一段：登录与认证（20秒）

> **画面**：登录页面 → 输入 shuhu / shuhuNB560 → 回车进入主界面

首先我们登录系统。后端使用 JWT Token 认证和 bcrypt 密码哈希，保障账户安全。登录后进入主界面，左侧是对话列表，中间是摄像头区域和聊天面板，右侧是识别记录。

---

## 第二段：摄像头实时画面（30秒）

> **画面**：点击摄像头按钮 → 允许权限 → 画面出现，切换滤镜（赛博→复古→素描）

点击底部摄像头按钮，浏览器会请求摄像头权限。这里使用 Web API `getUserMedia` 获取实时画面。

注意：**必须使用 HTTPS 连接**。HTTP 页面上浏览器安全策略会直接拒绝摄像头和麦克风访问。系统会显示清晰的错误提示，引导用户切换到 HTTPS 地址。

我们还内置了**三种实时滤镜**——赛博朋克风格、复古风格和素描风格，使用 Canvas 像素级处理实现。

---

## 第三段：多模态对话（40秒）

> **画面**：输入"你看到了什么？" → AI 根据摄像头画面回答

现在演示多模态对话。我对着摄像头，同时发送"你看到了什么？"AI 会调用视觉模型分析画面，返回描述。

系统支持两种 AI 调用模式：
1. **后端模式**：请求 → Flask → MIMO API
2. **直连模式**：浏览器直接调用 API，绕过后端

---

## 第四段：API 直连设置（30秒）

> **画面**：打开设置 → 滚动到 API 直连 → 开启 → 填入 API Key 和 Base URL

如果需要使用自己的 API Key，在设置中开启"API 直连"。

填入你的 API Key、Base URL、对话模型和视觉模型，浏览器的 `fetch()` 直接调用 OpenAI 兼容接口。这样一来，即使后端服务器有网络限制，前端也能正常工作。

这是完全原创的功能设计。

---

## 第五段：语音输入（30秒）

> **画面**：点击麦克风 → 说话 → 自动转文字 → 自动发送 → AI 回复

接下来演示语音输入。点击麦克风按钮，浏览器请求麦克风权限。

我说一句话："请介绍一下你自己"。系统通过 `MediaRecorder` 录制音频，发送到 STT 语音识别 API，转成文字后自动发送到对话框。AI 回复后，如果开启了 TTS 语音合成，还会自动朗读。

全程无需键盘操作，实现纯语音交互。

---

## 第六段：截图分析（30秒）

> **画面**：点击截图按钮 → AI 分析画面 → 结果显示在对话框中

点击相机按钮截图。系统抓取当前摄像头帧，压缩后发送到视觉模型进行分析。分析结果包含场景描述、物体识别和文字信息，直接显示在聊天界面中。

同时，截图也会保存到数据库，可在识别记录中查看历史。

---

## 第七段：前后对比（30秒）

> **画面**：打开工具栏 → 拍第一张 → 改变场景 → 拍第二张 → 点对比 → AI 分析差异

还有一个特色功能是**前后图像对比**。切换到工具栏，拍第一张照片，改变一下场景，再拍第二张。

点击对比按钮，系统分别对两张图片进行 AI 描述，然后请求模型分析两张图之间的差异和变化。

---

## 第八段：对话管理（20秒）

> **画面**：新建对话 → 切换 → 点击删除 → 确认弹窗

左侧边栏可以管理多个对话。支持新建、切换，删除时会弹出确认窗口。所有对话数据持久化存储在 SQLite 数据库中。

---

## 第九段：响应式适配（20秒）

> **画面**：缩小浏览器窗口 → 展示平板布局 → 再缩小展示手机布局

最后展示响应式适配。缩小窗口到平板宽度，左侧边栏自动折叠。继续缩小到手机宽度，摄像头区域和聊天面板上下排列。所有按钮和文字都能正常触控操作。

---

## 结尾（15秒）

> **画面**：回到完整桌面布局，展示 Sentio-AI Logo

以上就是 Sentio-AI 的核心功能演示。项目从视觉感知、语音交互到 AI 对话，构建了一个完整的多模态交互系统。所有代码开源，遵循细粒度 PR 规范，主分支始终保持可运行状态。

感谢观看。
